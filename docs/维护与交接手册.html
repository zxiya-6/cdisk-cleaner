工程路径职责
CleanMaster.Coresrc\CleanMaster.Core引擎：规则库、安全过滤器、扫描器、清理执行器、备份区、台账、自检

  • 备份移入为同卷改名（秒级）；跨卷自动复制 + 校验 + 删源。

03

构建与发布

环境要求：Windows 10 / 11 x64、.NET SDK 7.0+（开发机实测 SDK 7.0.100 可用）。

# 构建（三个工程）
dotnet build CleanMaster.sln -c Release

# 发布自包含版（目标机无需安装 .NET）
dotnet publish src\CleanMaster.App -c Release -r win-x64 --self-contained true -p:PublishReadyToRun=true -o publish\app
dotnet publish src\CleanMaster.Cli -c Release -r win-x64 --self-contained true -p:PublishReadyToRun=true -o publish\cli
  • 本机若存在多个 .NET 安装，运行框架依赖版需让 DOTNET_ROOT 指向含 net7 桌面运行时的安装；发布版自包含，不受影响；
  • 源码文件统一 UTF-8（带 BOM）；PowerShell 维护脚本同样需要 BOM（否则中文路径被按 GBK 误读）；
  • 解决方案文件为手写版本；不要依赖 dotnet new（部分环境被安全策略限制）。
04

规则库维护（核心资产）

生效优先级：%LOCALAPPDATA%\C盘清理助手\rules\rules.json（用户副本，在线更新/导入生成）> 程序目录 rules\rules.json（出厂版本）。

字段含义取值
id / group / name / note标识 / 分组 / 名称 / 说明文本
kind规则类型dirContents / files / emptyRecycleBin
paths目标路径（支持 %ENV% 与通配段）字符串数组
includeFiles / excludeFiles文件名过滤（通配符）字符串数组
strategy清理策略delete / backup / trash
risk风险等级safe / moderate / high
defaultChecked / recommend默认勾选 / 进入一键推荐true / false
requiresAdmin是否需要管理员true / false
minAgeDays只清理 N 天前文件（0 不限）整数
warnProcesses进程运行时提示字符串数组（无 .exe 后缀）

维护流程：改 rules.json → CleanMasterCli rules-check 校验 → 客户端点「工具 → 重载规则库」。新增类别示例：

{
  "id": "my-cache", "group": "应用与开发工具", "name": "我的工具缓存",
  "note": "缓存目录，可安全删除", "kind": "dirContents",
  "paths": ["%LOCALAPPDATA%\\MyTool\\cache"],
  "strategy": "delete", "risk": "safe", "defaultChecked": false
}

自定义保护：protected.json 的 customDeny 数组追加目录（位于其下的内容永不清理）。执行期内置保护不可通过配置关闭。

05

规则在线更新机制

流程：下载 → 解析 → 结构校验 → 安全预检 → 差异预览 → 确认 → 备份旧版 → 写入用户副本 → 复核（失败自动回滚）。

  • 命令：CleanMasterCli rules-update --url <URL|文件> [--check] [--yes]；GUI 在「工具」页；
  • 备份：rules.json.bak-yyyyMMddHHmmss（保留最近 5 份）+ 首次生成 rules.original.json 出厂快照；
  • 安全边界：仅下载、不上传；执行期安全名单无法被远程更新修改；非 HTTPS 且非本机地址时给出警告。

安全设计（五层防护）

  1. 规则层：类别路径来自受控规则库，只指向可再生成内容；
  2. 执行期：每个文件删除/移动前过 SafetyFilter（内置拒绝清单、条件白名单、符号链接拒绝、备份区自保护）；
  3. 交互层：预览 → 确认对话框（风险分级 + 高风险二次确认）→ 逐项排除；
  4. 可恢复层：trash / backup 策略把用户可见数据引向回收站与备份区；
  5. 审计层：全量台账 + 日志 + 空间前后实测双数值。

另：规则在线更新具备独立校验与回退；安全名单不可被远程修改。
