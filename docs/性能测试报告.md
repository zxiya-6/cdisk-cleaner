# C盘清理助手 v5.0 · 性能测试报告

> 测试日期：2026-09-16 · 测试机：本机（Windows 11 Pro 26200 / 32 逻辑核 / 16GB RAM / C 盘 400GB SSD）
> 版本：v5.0.0（release，自包含发布版）对比 CleanSuite v4.3（旧版，PowerShell 实现）

## 结论摘要

| 指标 | 旧版 v4.3 | 新版 v5.0 | 提升 |
|---|---|---|---|
| 全量扫描耗时（中位数） | 15.86 s | **2.19 s** | **7.2×** |
| GUI 冷启动就绪（中位数） | 3610 ms | **1105 ms** | **3.3×** |
| 扫描内存峰值（中位数） | 114.7 MB | **68.6 MB** | -40% |
| 启动后就绪内存（中位数） | 192.9 MB | **117.7 MB** | -39% |
| 扫描中途取消响应 | 无取消机制 | **≈130 ms** | 新增能力 |

数据规模：全量扫描 91,769 个文件 / 8.9 GB 可清理项（31 个类别），3 次重复运行结果一致。

## 测试环境

- 操作系统：Windows 11 专业版（10.0.26200），x64
- CPU：32 逻辑核 · 内存：15.7 GB · 系统盘：400 GB SSD（NTFS）
- 权限：管理员会话；v4.3 与 v5.0 均在相同机器、相同时间段内实测

## 方法学（口径统一）

- 扫描：v4.3 使用其自带无头扫描模式（`-ScanOnly`）；v5 使用 `scan` 命令。统一记录"进程启动→退出"墙钟时间与 WorkingSet 采样峰值（70~150ms 间隔）。
- 冷启动：统一以"进程启动 → 主窗口标题出现"计（v4.3 为 `C 盘清理套装` 主窗口，v5 为 `C盘清理助手 v5`）。
- 全部数据由脚本自动采集，脚本与原始数据随交付物提供（`Tests\bench-final.ps1`、`Docs\data\bench-final.json`）。
- 说明：v5 冷启动测试在清空 `DOTNET_ROOT` 环境变量的会话中进行，验证免运行时依赖。

## 清理执行与释放精度

- **样本级精度**：6 个受控文件（3.59 MB）备份→恢复→清空全流程；清空备份区后 C 盘可用空间 Δ = 3.58 MB，与文件真实大小偏差 0.3%（99.7% 吻合）。
- **真机单次释放**：用户临时文件清理单次释放 736.9 MB（台账记录值）；被占用文件（36 个）被正确跳过并记录原因。
- **端到端验收**：扫描→备份→恢复→清空→台账导出 11/11 通过（详见《验证记录与验收清单》）。

## 稳定性与可取消性

- 连续 3 次全量扫描：文件数 91,723–91,739（±0.02%），无内存增长、无崩溃。
- 扫描中途取消：实测 127–134 ms 内响应停止（全量扫描进行中触发）。
- 研发与验收期间累计约 40+ 次进程启停（GUI/CLI），无未处理异常导致的中断。

## 已知限制

- 内存为 WorkingSet 采样峰值，非 ETW 精确口径；缓存热态下数值可能波动 ±10%。
- GUI"流畅度"以脚本化交互与截图验证覆盖（扫描中进度刷新、随时取消），未做长时间人工体验测试。
- 旧版对比以 v4.3 自带扫描能力为基准；旧版无对应"备份/台账"功能，未做功能对等折算。
