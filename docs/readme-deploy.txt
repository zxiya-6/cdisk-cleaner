C盘清理助手 v5.0.0（免安装版）
================================

一键开始
  双击  C盘清理助手.exe  即可使用。
  建议右键"以管理员身份运行"，以覆盖系统级缓存（Windows 临时文件、更新缓存、日志等）。

安装包
  同一目录（C盘清理工具\）提供标准安装程序：
    C盘清理助手_v5.0.0_安装包_x64.exe
  双击进入向导式安装（开始菜单 / 桌面快捷方式 / 系统"程序和功能"卸载）。
  免安装版与安装版可任选其一。

程序位置
  C盘清理助手.exe          主程序（自包含运行时，无需安装 .NET；断网可用）
  tools\CleanMasterCli.exe 命令行版（自动化与维护用）
  rules\                   清理规则库（可编辑、可在"工具"页在线更新）
  Docs\                    文档中心（建议先双击 Docs\index.html）

快速了解
  · 扫描约 2 秒（实测 91,769 个文件 / 8.9GB 内容，2.19 秒）
  · 安全项默认勾选；谨慎/高风险项默认不勾选、需确认
  · 删除前有预览与确认；清理可备份、可恢复、全程有台账

文档（Docs\ 内）
  使用说明 · 维护与交接手册 · 性能测试报告 · 能力对照清单 · 验证记录与验收清单
  每份均有 HTML 阅读版与 Markdown 可编辑版。

源码与构建
  完整源码、构建脚本与测试脚本位于 GitHub 仓库：
    https://github.com/zxiya-6/cdisk-cleaner
  （已按交付要求移出本机）

数据与隐私
  全部数据保存在本机：%LOCALAPPDATA%\C盘清理助手\
  （配置 / 日志 / 台账 / 备份区）。不上传任何数据；规则在线更新仅"下载"。
  便携模式：在本目录新建空文件 portable.flag，数据改存本目录 data\。

卸载
  免安装版：删除本目录即可。安装版：开始菜单"卸载 C盘清理助手"或"设置→应用"。
