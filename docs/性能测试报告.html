08

稳定性与可取消性

  • 连续 3 次全量扫描：文件数 91,723–91,739（±0.02%），无内存增长、无崩溃。
  • 扫描中途取消：实测 127–134 ms 内响应停止（全量扫描进行中触发），界面保持响应。
  • 研发与验收期间累计 40+ 次进程启停（GUI / CLI / 安装版 / 发布版），无未处理异常导致的中断。
  • 脚本化界面交互（扫描→详情→确认对话框→取消→五页签遍历）连续 3 轮完整通过。
