# C盘清理助手 v5.0 · 维护与交接手册

> 面向接手人：架构、构建发布、规则库维护、数据与日志、测试体系、安全设计、交接检查清单。

## 1. 架构总览

```
rules.json ──► Scanner（并行扫描/进度/取消）
                  │
                  ▼
           预览与勾选（GUI/CLI）
                  │
                  ▼
         CleanExecutor ──逐文件──► SafetyFilter（安全保护名单，执行期强制复核）
                  │
        ┌─────────┼──────────┐
        ▼         ▼          ▼
     永久删除   备份区     回收站
                  │
                  ▼
             Ledger（JSONL 台账）──► CSV / HTML 导出
```

三个工程（同一解决方案）：

| 工程 | 路径 | 职责 |
|---|---|---|
| CleanMaster.Core | `src\CleanMaster.Core` | 引擎：规则库、安全过滤器、扫描器、清理执行器、备份区、台账、自检 |
| CleanMaster.Cli | `src\CleanMaster.Cli` | 命令行：scan / clean / backup / ledger / rules-update / selftest 等 |
| CleanMaster.App | `src\CleanMaster.App` | WPF 桌面界面（五个页签），零装饰高信息密度风格 |

关键设计：
- **扫描与清理共用同一套路径解析/过滤逻辑**（RulePathResolver + FileWalker），保证"预览到的"与"会处理的"一致；
- **执行期安全名单独立于规则库**：即使规则被改坏，系统关键区与个人目录在删除动作前仍会被逐文件拒绝；
- 备份区与数据目录分离：备份移入为**同卷改名**（秒级、无拷贝），跨卷时自动复制+校验+删源。

## 3. 构建与发布

环境要求：Windows 10/11 x64、.NET SDK 7.0+（开发机实测 SDK 7.0.100 可用）。

```powershell
# 构建（三个工程）
dotnet build CleanMaster.sln -c Release

# 发布自包含版（无需目标机安装 .NET）
dotnet publish src\CleanMaster.App -c Release -r win-x64 --self-contained true -p:PublishReadyToRun=true -o publish\app
dotnet publish src\CleanMaster.Cli -c Release -r win-x64 --self-contained true -p:PublishReadyToRun=true -o publish\cli
```

注意事项：
- 本机若存在多个 .NET 安装（如工具自带的运行时），运行框架依赖版需设置 `DOTNET_ROOT` 指向含 net7 桌面运行时的安装目录；**发布版为自包含，不受此影响**；
- 源码文件统一 UTF-8（带 BOM）；PowerShell 维护脚本同样需要 BOM（否则中文路径会被按 GBK 误读）；
- 仓库内 `CleanMaster.sln` 为手写版本，可直接用；不要依赖 `dotnet new`（部分环境被安全策略限制注册表访问）。

## 4. 规则库维护（核心资产）

生效优先级：`%LOCALAPPDATA%\C盘清理助手\rules\rules.json`（用户副本，在线更新/导入生成）> 程序目录 `rules\rules.json`（出厂版本）。

字段速查（完整字段见 `rules\rules.json`）：

| 字段 | 含义 | 取值 |
|---|---|---|
| id / group / name / note | 标识 / 分组 / 名称 / 说明 | 文本 |
| kind | 规则类型 | dirContents / files / emptyRecycleBin |
| paths | 目标路径（支持 %ENV% 与通配段，如 `...\User Data\*\Cache`） | 字符串数组 |
| includeFiles / excludeFiles | 文件名过滤（通配符） | 字符串数组 |
| strategy | 清理策略 | delete / backup / trash |
| risk | 风险等级 | safe / moderate / high |
| defaultChecked / recommend | 默认勾选 / 进入一键推荐 | true / false |
| requiresAdmin | 是否需管理员 | true / false |
| minAgeDays | 只清理 N 天前文件（0 不限） | 整数 |
| warnProcesses | 进程运行时提示（无 .exe 后缀） | 字符串数组 |

维护流程：改 `rules.json` → 运行 `CleanMasterCli rules-check` 校验 → 客户端点「工具 → 重载规则库」。新增类别示例：

```json
{
  "id": "my-cache", "group": "应用与开发工具", "name": "我的工具缓存",
  "note": "缓存目录，可安全删除", "kind": "dirContents",
  "paths": ["%LOCALAPPDATA%\\MyTool\\cache"],
  "strategy": "delete", "risk": "safe", "defaultChecked": false
}
```

自定义保护：`protected.json` 的 `customDeny` 数组追加目录（位于其下的内容永不清理）。执行期内置保护（系统核心、个人文档、密钥目录、根目录）不可通过配置关闭。

## 5. 规则在线更新机制

流程：`下载（URL/本地文件）→ JSON 解析 → 结构校验（重复 id/缺字段）→ 安全预检（路径触碰保护名单时给出警告）→ 差异预览（新增/移除/修改）→ 用户确认 → 备份旧版 → 写入用户副本 → 复核（失败自动回滚）`。

- 命令：`CleanMasterCli rules-update --url <URL|文件> [--check] [--yes]`；GUI 在「工具」页。
- 备份：`rules.json.bak-yyyyMMddHHmmss`（保留最近 5 份）+ 首次生成 `rules.original.json` 出厂快照。
- 安全边界：仅下载、不上传；**执行期安全名单无法被远程更新修改**；非 HTTPS 且非本机地址时给出警告。

## 6. 数据文件（%LOCALAPPDATA%\C盘清理助手\）

| 文件/目录 | 内容 | 备注 |
|---|---|---|
| config.json | 备份区路径、默认模式、规则更新地址等 | 删除后自动重建默认值 |
| ledger\ledger.jsonl | 台账（每行一次操作） | 追加式、防损坏；可导出 |
| logs\app-YYYYMMDD.log | 运行日志 | 按天分文件 |
| backup\<会话>\ | 备份文件（data\ + manifest.jsonl + meta.json） | 清空后释放空间 |
| rules\rules.json | 用户规则副本（如有） | 优先于出厂规则 |

便携模式：程序目录放置 `portable.flag`，数据改存 `程序目录\data\`。

## 7. 日志与排障

| 现象 | 排查 |
|---|---|
| 双击无窗口（框架依赖版） | 检查是否缺少 .NET 桌面运行时；改用自包含发布版 |
| 规则库加载失败 | `rules-check` 看问题列表；「工具」页可重载；坏文件可用 `.bak-*` 还原 |
| 部分文件被跳过 | 查看结果"跳过原因"：被占用（关程序重试）/ 无权限（提权）/ 位于保护名单 |
| 备份移入慢 | 备份区被配置到其他磁盘时跨卷复制；改回同盘（默认）恢复秒级 |
| DISM 报错 | 需管理员；退出码与输出已记录在工具页文本框；请勿中途关闭 |
| 界面语言/编码异常 | 系统区域设置非中文时界面仍为中文；路径日志均 UTF-8 |

## 9. 安全设计（五层防护）

1. **规则层**：类别路径来自受控规则库，只指向可再生成内容；
2. **执行期**：每个文件删除/移动前过 SafetyFilter（内置拒绝清单、条件白名单、符号链接拒绝、备份区自保护）；
3. **交互层**：预览 → 确认对话框（含风险分级与高风险二次确认）→ 逐项排除；
4. **可恢复层**：trash / backup 策略把用户可见数据引向回收站与备份区；
5. **审计层**：全量台账 + 日志 + 空间前后实测双数值。

另：规则在线更新有独立校验与回退，安全名单不可被远程修改。
