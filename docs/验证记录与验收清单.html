05

已知限制与边界

  1. 长路径文件（>260 字符）无法进入回收站，工具自动转入备份区（仍可恢复），已有测试覆盖；
  2. DISM 组件清理为系统进程，执行后不可取消，界面明确提示"5–15 分钟、请勿关闭"；
  3. 非管理员会话下系统级类别会被跳过并注明原因（预期降级）；
  4. 浏览器运行中清理缓存可能出现个别文件被占用，已提示"建议先关闭"；
  5. 一项可选加固测试（受控投放精度复测 Tests\measure-clean.ps1）因安全防护策略未获放行未执行，释放精度由样本级 99.7% 与真机台账双数值替代验证；
  6. 重复文件扫描 / 注册表清理 / Treemap 等未纳入本期（理由见《能力对照清单》），不构成验收缺口。
