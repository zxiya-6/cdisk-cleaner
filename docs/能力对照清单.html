03

重点能力落地明细

分类可视化：类别行内含风险色点（安全绿 / 谨慎黄 / 高风险红），大小列显示可读体积；右侧详情面板展示 Top 文件、扫描位置与被跳过项；大文件页给出全盘 Top 列表并支持回收站删除。相比位图式 treemap，信息密度更高、无障碍更好、性能更稳。

规则可维护：所有类别、路径模板（含 %ENV% 与通配段）、文件过滤、风险等级、默认勾选、管理员要求、最小文件年龄均在 rules\rules.json 声明；改规则不改代码；rules-check 一键校验；protected.json 追加自定义保护目录；并支持在线更新与本地导入。

清理建议分级：安全级=可自动重建的缓存/临时文件（默认勾选）；谨慎级=影响体验或有恢复成本（默认不勾选、黄色标识、确认框逐项提示）；高风险级=不可逆操作（默认不勾选 + "我已了解"勾选后放行）。

04

不采纳项与完整理由

  • 重复文件扫描：内容级去重要全盘读取（分钟级起步，破坏"3 秒扫描"体验）；删除重复文件天然触碰个人文档/照片保护区，与"只清可再生成垃圾"的定位冲突；对标工具普遍做成独立模块。后续方案：独立"重复文件"模块（只读检测、仅移回收站、默认全不选、保护个人目录树）。
  • 注册表清理 / 启动项管理 / 驱动与服务调优：与"安全、快速、可追溯"的定位冲突；出错修复成本高，且与验收边界（不做注册表深度清理、驱动级优化、系统服务调优）明确不符。
  • 计划任务自动清理：后台静默删除在本工具语境下不可接受；所有删除都必须经过"预览→确认→台账"链路。
  • 账号 / 云同步：坚持本地单机；规则在线更新为"只下载不上传"，不引入任何账号体系。
  • Treemap：交互成本高、信息密度低于列表方案；如需方块图分析，仍可使用旧版目录内附带的 SpaceSniffer。

后续可选增强（按建议优先级）

  3. 清理前导出"本次计划 JSON"（供审计与复现）
