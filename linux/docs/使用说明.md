# 磁盘清理助手（Linux 版）使用说明

版本：1.0.0（release）· 平台：Linux x86_64 · 双形态：CLI + 图形界面

## 一、安装

提供四种发行版安装包（见 `installer/dist/`）：

| 发行版 | 安装包 | 安装命令 |
|---|---|---|
| Debian / Ubuntu | `cleanmaster_1.0.0_amd64.deb` | `sudo apt install ./cleanmaster_1.0.0_amd64.deb` |
| Fedora / RHEL | `cleanmaster-1.0.0-1.x86_64.rpm` | `sudo dnf install ./cleanmaster-1.0.0-1.x86_64.rpm` |
| Arch / Manjaro | `cleanmaster-1.0.0-1-x86_64.pkg.tar.zst` | `sudo pacman -U ./cleanmaster-1.0.0-1-x86_64.pkg.tar.zst` |
| 任意发行版 | `CleanMaster-1.0.0-x86_64.AppImage` | `chmod +x` 后直接运行 |

卸载：

- Debian/Ubuntu：`sudo apt remove cleanmaster`
- Fedora：`sudo dnf remove cleanmaster`
- Arch：`sudo pacman -R cleanmaster`
- AppImage：删除文件即可

安装后提供两个命令：

- `cleanmaster` —— 命令行工具
- `cleanmaster-gui` —— 图形界面（桌面菜单「磁盘清理助手」）

## 二、图形界面（cleanmaster-gui）

六个页签：

1. **扫描清理**：开始扫描 → 勾选类别（默认已选推荐项）→「清理选中…」选择清理模式。
   - 标准：按类别策略（缓存删除、隐私移回收站）
   - 全部备份：所有内容移入备份区（最安全，可一键恢复）
   - 全部永久删除：立即释放空间（不可恢复）
   - 风险标签：绿色=安全 / 橙色=谨慎 / 红色=高风险（默认不勾选）
2. **备份区**：列出每次备份会话，可恢复选中会话（冲突自动改名）或清空。
3. **台账**：全部操作留痕，可导出 CSV / HTML 报告。
4. **规则**：规则库信息、校验、在线更新（需在配置中设置 `ruleUpdateUrl`）。
5. **自检**：内置 9 项自检（安全过滤器、符号链接、权限、长路径、回收站、备份区、台账等）。
6. **关于**：版本、数据目录、设计原则。

## 三、命令行（cleanmaster）

```bash
cleanmaster version          # 版本信息
cleanmaster scan             # 全量扫描
cleanmaster scan --category user-temp,thumbnails   # 只扫指定类别
cleanmaster clean --category user-temp --dry-run   # 预演
cleanmaster clean --category user-temp --yes       # 实际清理
cleanmaster clean --category all --mode backup --yes   # 全部移入备份区
cleanmaster bigfiles         # 大文件扫描（默认 >100MB）
cleanmaster backup-list      # 备份区会话
cleanmaster backup-restore --session <ID>          # 恢复备份
cleanmaster backup-purge --all --yes               # 清空备份区
cleanmaster ledger           # 台账
cleanmaster ledger-export --format csv --out out.csv
cleanmaster rules-check      # 校验规则库
cleanmaster rules-update --check   # 检查规则更新
cleanmaster selftest         # 内置自检
cleanmaster journal-vacuum --size 100M --time 7d --yes   # 压缩 systemd 日志（需 sudo）
```

全部命令均支持 `--json` 输出（机器可读）。

## 四、数据与配置

| 项目 | 路径 |
|---|---|
| 数据目录（备份区/台账） | `$XDG_DATA_HOME/cleanmaster`（默认 `~/.local/share/cleanmaster`） |
| 配置文件 | `$XDG_CONFIG_HOME/cleanmaster/config.json` |
| 规则库（内置） | `/usr/lib/cleanmaster/cli/rules/`（AppImage 在包内） |
| 用户规则覆盖 | `~/.config/cleanmaster/rules/` |
| 受保护路径清单 | `rules/protected.json`（默认空，可自定义追加） |

可用环境变量：`CC5_DATA_DIR`（数据目录）、`XDG_DATA_HOME`、`XDG_CONFIG_HOME`。

## 五、安全机制

- **保护名单**：根目录内核文件（vmlinuz/initrd.img/swapfile 等）拒绝；`/proc /sys /dev /run /lost+found` 整体拒绝；`/var` 仅白名单子路径；`/usr /etc /opt /boot /snap` 条件保护；HOME 下 `Documents/Desktop/Pictures/...`、密钥目录（`.ssh/.gnupg/.password-store/.aws/.azure/.kube`）整树拒绝；多用户时只允许当前用户主目录。
- **删除可恢复**：默认策略（Backup/Trash）不清除数据；回收站策略写入 freedesktop 回收站（含 `.trashinfo`）。
- **高风险不默认做**：Docker 缓存、旧内核、系统快照等高风险类别不纳入。
- **台账留痕**：每次操作记录类别、大小、模式、时间，可导出审计。

## 六、常见问题

- **清理提示无权限**：部分系统目录需要管理员。GUI 请用 `sudo cleanmaster-gui`，CLI 用 `sudo cleanmaster ...`。
- **journal-vacuum 需要 sudo**：该命令通过 `journalctl --vacuum-*` 压缩日志，不直接删除 journal 文件。
- **AppImage 无法运行**：确认已 `chmod +x`；若提示 FUSE 缺失，可解包运行：`./CleanMaster-1.0.0-x86_64.AppImage --appimage-extract && ./squashfs-root/AppRun`。
- **规则更新失败**：在线地址需在 `config.json` 的 `ruleUpdateUrl` 配置，更新前会自动备份旧规则到用户规则目录。
