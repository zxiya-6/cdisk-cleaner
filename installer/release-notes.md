# C盘清理助手 v5.0.0

基于 .NET 7 全新重写的 Windows C 盘清理工具：快、稳、安全、可追溯。

## 亮点

- **快**：全盘扫描 2 秒级（实测 91,769 个文件 2.19 秒；对比旧版 15.86 秒，提升 7.2 倍）
- **稳**：冷启动约 1.1 秒（旧版 3.6 秒）；扫描内存峰值较旧版降低 40%；界面全程可取消不卡死
- **安全**：31 类清理规则；安全项默认勾选、高风险项二次确认；仅清理可再生成内容，不触碰个人文件
- **可恢复**：三种清理方式（标准 / 全部备份 / 全部永久删除）；备份区随时一键恢复
- **可追溯**：操作台账记录每笔清理（时间/类别/数量/释放空间/结果），支持 CSV / HTML 导出
- **可扩展**：规则库 JSON 化，可在应用内在线更新（只下载不上传，随时可回退）
- **零依赖**：自包含发布，目标机无需安装 .NET；断网可用

## 使用要求

- Windows 10 / 11 x64
- 建议以管理员身份运行（覆盖系统级缓存类别）

## 界面与文档

安装后可直接打开内置《文档中心》；命令行工具位于 `tools\CleanMasterCli.exe`。

## 数据与隐私

所有数据仅保存在本机（`%LOCALAPPDATA%\C盘清理助手`），不上传任何数据；规则在线更新仅执行“下载”，且安全保护名单不可被远程修改。
